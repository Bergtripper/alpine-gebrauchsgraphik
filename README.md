# Alpine Gebrauchsgraphik

**Atlas of Alpine Visual Culture · 1900—1970**

A DOTZERO research project exploring Alpine applied graphic culture through people, works, places, clients, publications, archives, visual languages and their connections.

## Development

Prerequisites: Node.js 22+

```bash
npm install
npm run dev
```

## Production build

```bash
npm run lint
npm run build
```

The project is deployed to GitHub Pages automatically from the `main` branch via GitHub Actions.
